## 📋 About This System
This is a dedicated, simplified business management web application built specifically for **Mansoori Oil** to handle daily commercial hisab-kitab, rapid POS counter billing, customer udhar ledgers, and oil mill supplier payables.

### 5 Core Modules Included:
1. **📊 Executive Dashboard**: Zoho-inspired 2-column control deck with top-selling oil items carousel, recent transactions, and Pending Actions tracking panel.
2. **⚡ Fast POS Billing Counter**: 3-second rapid billing, barcode item lookup, auto-calculated 5% edible oil GST, and one-click printable thermal bill receipts.
3. **👥 Customer Management (Khata / Udhar-Jama)**: Wholesale buyers credit ledger, running balance tracking, one-click WhatsApp payment reminders, and payment (Jama) entries.
4. **🏭 Supplier Management (Oil Mills & Payables)**: Raw crude oil tankers tracking, inward goods invoices, and supplier payment reconciliation.
5. **🛢️ Inventory Management (Oil Stock)**: Real-time stock decrements upon billing, Tins/Jars/Pouches/Cans inventory units, and low-stock alarms.

## 🚀 How to Deploy on GitHub Pages (In 30 Seconds)

1. Create a new public repository on GitHub (e.g. `mansoori-oil`).
2. Upload the files inside this `Mansoori-Oil` folder (`index.html`, `Mansoori_Oil_Prototype_and_Flow.pdf`, `.nojekyll`, `README.md`).
3. In your GitHub repository:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment**:
     - Source: **Deploy from a branch**.
     - Branch: **`main`** (or `master`) and folder **`/(root)`**.
     - Click **Save**.
4. Your live link will be ready at:  
   `https://<your-username>.github.io/<repo-name>/`
5. Share this live link directly with Mansoori Oil to test on mobile, tablet, or PC!
